RB Games Maven repository

The public APIs of RB Games plugins, for developers who build on them. Reading needs no account or token. Released versions never change, and snapshots aren't published here.

Maven

Add the repository to your pom.xml:

<repositories>
    <repository>
        <id>rbgames</id>
        <url>https://repo.rbgames.be</url>
    </repository>
</repositories>

Then depend on a plugin's API, with the coordinates from that plugin's documentation:

<dependency>
    <groupId>be.rbgames</groupId>
    <artifactId>plugin-api</artifactId>
    <version>version</version>
    <scope>provided</scope>
</dependency>

Gradle

repositories {
    maven("https://repo.rbgames.be")
}
